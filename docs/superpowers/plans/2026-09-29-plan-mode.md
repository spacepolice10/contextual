# Plan Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third screen (Plan mode) to `contextual` — a mind-map-style planner with hierarchical nodes, cross-links, JSON persistence, read-only dual-pane UI, and CLI/MCP commands.

**Architecture:** New `src/plan/` module with four files: `model.rs` (pure data + command logic), `commands.rs` (parsing/dispatch), `render.rs` (ratatui widgets), `mod.rs` (screen integration). Plan mode is a new `Mode` variant in `App`. CLI subcommands via clap. Picker integration for `.plan.json` files.

**Tech Stack:** Rust, ratatui 0.29, crossterm 0.28, clap 4.5 (derive), serde, serde_json, anyhow

**Spec:** `docs/superpowers/specs/2026-09-29-plan-mode-design.md`

## Global Constraints

- All text indexing is char-based (consistent with existing codebase)
- JSON is pretty-printed (git-friendly)
- Default plan file: `~/.contextual/plan.json`
- UI is read-only — all mutations via commands
- Tests are inline `#[cfg(test)]` modules (no `tests/` dir)
- `cargo clippy -- -D warnings` must pass
- `cargo test` must pass

## Review Focus

1. **Invalid node ID** — commands referencing non-existent IDs return clear errors
2. **Duplicate links** — creating a link that already exists is an error
3. **Orphan nodes** — deleting a parent must handle children (subtree delete)
4. **JSON round-trip** — serialize → deserialize produces identical graph
5. **Cross-link cycles** — `connect_create` allows cycles (by design, escape hatch)

pub fn is_plan_file(path: &Path) -> bool {
    // Check .plan.json extension
    if path.extension().and_then(|e| e.to_str()) == Some("json") {
        if let Some(stem) = path.file_stem().and_then(|s| s.to_str()) {
            if stem.ends_with(".plan") {
                return true;
            }
        }
        // Check JSON structure for "nodes" key
        if let Ok(content) = std::fs::read_to_string(path) {
            if let Ok(json) = serde_json::from_str::<serde_json::Value>(&content) {
                return json.get("nodes").is_some();
            }
        }
    }
    false
}
